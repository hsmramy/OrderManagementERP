# OrderManagementERP

A production-grade ERP order management system built with .NET 8, demonstrating senior-level architecture, async patterns, DDD, comprehensive testing, and scalability principles.

## Architecture

- **Clean Architecture**: Separated concerns across layers
- **SOLID Principles**: Well-designed, maintainable code
- **Domain-Driven Design**: Business logic at the core
- **Async/Await**: Scalable, responsive API
- **Repository Pattern**: Abstracted data access
- **Comprehensive Testing**: 90%+ code coverage

## Tech Stack

- .NET 8
- ASP.NET Core
- Entity Framework Core
- Redis (caching)
- xUnit & Moq (testing)
- SQL Server

## Learning Goals

This project demonstrates:
- How senior engineers structure systems
- Best practices for scalable APIs
- Testing strategies and patterns
- Performance optimization
- Real-world architecture decisions
